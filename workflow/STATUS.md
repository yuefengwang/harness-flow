## 📋 多项目管理

本工作流支持通过 `repo/` 目录管理多个项目。使用以下命令初始化当前开发项目：

```bash
./dev-init.sh              # 交互式选择项目
./dev-init.sh --list       # 列出所有可用项目
./dev-init.sh <project>    # 直接指定项目
```

`dev init` 后，当前焦点会自动更新，并加载项目上下文到 `workflow/current-context.md`。

## 🚦 状态机规则

1. **项目初始化:** 首次开发一个项目时：
   - 运行 `./dev-init.sh` 选择项目。
   - 系统自动加载项目 README + 目录结构作为上下文。
   - 更新 **当前焦点**。

2. **新任务:** 在已初始化的项目中开始新任务时：
   - 在 `workflow/tasks/<task-id>/` 创建文件夹。
   - 将 `workflow/templates/` 下的所有文件复制到该文件夹。
   - 在上方的 **任务板** 中添加一行。
   - 设置 **当前焦点**。

3. **推进:**
   - 更新任务文件夹中对应的 `.md` 文件。
   - 当某个阶段的准则达成时，在任务板中更新 **阶段**。

4. **切换项目:**
   - 运行 `./dev-init.sh` 重新选择项目。
   - 系统会更新上下文和当前焦点。

5. **归档:**
   - 将任务文件夹移动到 `workflow/archive/history/`。
   - 在任务板中将状态标记为 `完成 (Done)`。
